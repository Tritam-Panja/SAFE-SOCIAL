# Cloudflare R2 Media Setup & Configuration Guide — Fizzy

Fizzy utilizes an isolated, two-tier storage architecture to guarantee that no user-generated content is made publicly accessible before strict administrative safety review.

---

## 1. Bucket Isolation Architecture

Create **two separate private buckets** in your Cloudflare dashboard:

```
[ Child Upload ]
       │ (Signed PUT URL - 15m expiration)
       ▼
┌───────────────────────────────┐
│ 1. Quarantine Bucket          │
│ (fizzy-media-quarantine)      │  <--- Private: Zero public access
└──────────────┬────────────────┘
               │
               ▼ (Admin Safety Approval via /moderation/:id/review)
┌───────────────────────────────┐
│ 2. Approved Bucket            │
│ (fizzy-media-approved)        │  <--- Served exclusively through CDN domain
└───────────────────────────────┘
```

1. **Quarantine Bucket (`fizzy-media-quarantine`)**:
   - Stores raw uploads immediately after child upload.
   - **Never attach a public custom domain to this bucket.**
   - All access is restricted to pre-signed URLs generated by the API for authorized administrators and media owners.
2. **Approved Bucket (`fizzy-media-approved`)**:
   - Holds approved images, videos, and generated thumbnails.
   - Associated with a Cloudflare Custom Domain or CDN Worker (e.g., `https://cdn.fizzykids.safe`).

---

## 2. Generating Cloudflare R2 S3 API Credentials

1. Navigate to **Cloudflare Dashboard** > **R2 Object Storage**.
2. Click **Manage R2 API Tokens**.
3. Click **Create API Token**.
4. Configure permissions:
   - **Permission**: `Object Read & Write`.
   - **Apply to**: Specific buckets (`fizzy-media-quarantine`, `fizzy-media-approved`).
   - **TTL**: Select according to your organization's key rotation policies.
5. Save the generated credentials:
   - `Access Key ID`
   - `Secret Access Key`
   - `Account ID` (found in the right-hand panel of the R2 overview page).

---

## 3. Configuring `.env`

Update your application `.env` file:

```ini
STORAGE_DRIVER=r2
R2_ACCOUNT_ID=d9a4b87e1234567890abcdef12345678
R2_ACCESS_KEY_ID=b3f947e09123847abcd87421
R2_SECRET_ACCESS_KEY=894172fbd89a7412e09847120398471239847123
R2_BUCKET_QUARANTINE=fizzy-media-quarantine
R2_BUCKET_APPROVED=fizzy-media-approved
R2_PUBLIC_DOMAIN=https://cdn.fizzykids.safe
```

---

## 4. Local Development Storage Fallback

When `STORAGE_DRIVER=local` (or R2 credentials are left blank), Fizzy automatically switches to its local development storage adapter (`LocalDevStorageProvider`).
- Quarantined files are saved to `apps/api/uploads/`.
- Local pre-signed URLs route to `/api/v1/media/local-upload` and `/api/v1/media/preview`.
- Strict owner and admin authentication checks remain enforced locally.
